## What Already Works

### Data Download

The module `src/utils/download.py` provides three functions that automatically download the raw datasets and place them in `data/raw/`:

| Function | Dataset | File | Source |
|----------|---------|------|--------|
| `download_telco()` | Telco Customer Churn | `telco.csv` | IBM GitHub (direct CSV download) |
| `download_bank()` | Bank Marketing | `bank.csv` | UCI Repository (ZIP, auto-extracted) |
| `download_ecom()` | E-Commerce Shopper | `ecom.csv` | UCI Repository (direct CSV download) |

Each function checks if the file already exists and skips the download if so.

### Complete Data Preparation Pipeline (One Command)

**`src/setup_data.py`** orchestrates **both download and preprocessing** in a single call and imports the preprocessing helpers from `src/utils/preprocess.py`:

```bash
python src/setup_data.py
```

This script:
1. **Downloads** all three datasets to `data/raw/` (skips if already present).
2. **Applies a uniform 7-step cleaning pipeline** to each dataset:
    - Remove exact duplicate rows
    - Normalize column names (strip, replace spaces/slashes with underscore)
    - Strip leading/trailing whitespace from all string cells
    - Replace placeholder values (`"unknown"`, `"nonexistent"`, `"?"`, `" "`, `""`, and – only in specified columns – `999`) with `NaN`
    - Convert object columns that are ≥95 % numeric to numeric dtype
    - Basic imputation (median for numeric, mode for categorical; target excluded)
    - Encode target variable to binary `0`/`1` (integer)
3. **Saves clean datasets** to `data/processed/` ready for modelling.

**For colleagues:** After cloning and pulling, simply run `python src/setup_data.py` from the `src/` directory to get all datasets downloaded and cleaned in one go.

### Exploratory Data Analysis

After data preparation, run `src/analysis.py` to perform comprehensive EDA on the **raw** datasets:

```bash
python src/analysis.py
```

This script writes:
- **Text report:** `reports/eda_report.txt` (appended on each run)
- **JSON summaries:** `reports/summary_<dataset>.json` (shape, missing values, target distribution, outlier counts, cardinality, duplicates)
- **Correlation heatmaps:** `reports/plots/corr_heatmap_<dataset>.png` (visualize feature relationships)

The analysis detects:
- Missing values and placeholder patterns
- Target imbalance
- Numerical outliers (IQR-based)
- Scale differences (flagged if factor > 100)
- Categorical high-cardinality features
- Data quality issues (leading/trailing spaces, coercion problems)
- Strong feature correlations (|r| > 0.9)

## How You Can Already Use the Data

### Cleaned Data
After running `setup_data.py`, all datasets are ready for modelling:

```python
import pandas as pd
telco_clean = pd.read_csv("data/processed/telco_clean.csv")
bank_clean = pd.read_csv("data/processed/bank_clean.csv")
ecom_clean = pd.read_csv("data/processed/ecom_clean.csv")
```

All targets are binary integers (1 = positive class, 0 = negative class). Missing values are imputed, placeholders removed.

**Important:** Numerical features are **not scaled** yet. Scaling will be applied inside the evaluation pipeline (e.g., using `StandardScaler` within cross‑validation).

### Raw Data
For reference or debugging:

```python
telco_raw = pd.read_csv("data/raw/telco.csv")   # comma-separated
bank_raw = pd.read_csv("data/raw/bank.csv")     # semicolon-separated
ecom_raw = pd.read_csv("data/raw/ecom.csv")     # comma-separated
```

Original target values: `Churn` (Yes/No), `y` (yes/no), `Revenue` (True/False).
